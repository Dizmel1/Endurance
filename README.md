# Игровой симулятор инвестиционного рынка

Проект представляет собой Web-приложение, разработанное в рамках выпускной квалификационной работы. Информационная система предназначена для обучения пользователя базовым принципам работы с валютными активами, формирования виртуального инвестиционного портфеля и выполнения учебных торговых операций.

В системе реализованы регистрация и авторизация пользователей, создание стартового портфеля, просмотр доступных валютных активов, получение актуальных котировок, покупка активов, просмотр истории операций, отображение купленных активов и обучающий модуль.

## Основные возможности

- регистрация пользователя;
- авторизация пользователя;
- автоматическое создание стартового учебного портфеля;
- отображение текущего состояния портфеля;
- просмотр доступных валютных активов;
- получение актуальных валютных котировок;
- покупка валютных активов за виртуальный баланс;
- просмотр истории операций;
- просмотр купленных активов;
- отображение профиля пользователя;
- обучающий модуль с текстовыми уроками и тестом;
- проверка REST API через Swagger UI.

## Загрузка проекта


## Настройка базы данных PostgreSQL

Перед запуском приложения необходимо создать базу данных PostgreSQL.

Пример названия базы данных:

```text
endurance
```

Параметры подключения к базе данных указываются в файле:

```text
src/main/resources/application.properties
```

Пример настроек подключения:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/endurance
spring.datasource.username=postgres
spring.datasource.password=postgres
```

При необходимости имя пользователя, пароль и название базы данных нужно изменить в соответствии с локальными настройками PostgreSQL.

## Запуск Redis

Redis используется для хранения пользовательских сессий приложения.

Если Redis запускается через Docker, можно использовать команду:

```bash
docker run --name endurance-redis -p 6379:6379 -d redis
```

Если контейнер уже был создан ранее, его можно запустить командой:

```bash
docker start endurance-redis
```

Проверить список запущенных контейнеров можно командой:

```bash
docker ps
```

Если Redis в проекте временно не используется или хранение сессий через Redis отключено, запуск Redis может не потребоваться.

## Порядок работы с приложением

После запуска приложения пользователь должен открыть страницу регистрации и создать учетную запись. После успешной регистрации система автоматически создает стартовый учебный портфель с виртуальным балансом.

Далее пользователь может выполнить вход в систему и перейти на главную страницу. На главной странице отображаются данные пользователя, информация о портфеле, доступные валютные активы, актуальные курсы и история операций.

Для покупки актива пользователь выбирает доступную валютную пару, указывает количество и подтверждает операцию. После выполнения сделки система обновляет свободный баланс портфеля, создает или изменяет позицию пользователя и сохраняет операцию в истории транзакций.

В разделе «Мои активы» отображаются купленные активы, их количество, средняя цена покупки, текущий курс, стоимость позиции и финансовый результат.

В разделе «Обучение» пользователь может ознакомиться с учебными материалами и пройти небольшой тест по основным понятиям инвестиционного симулятора.

## Особенности текущей версии

В текущей версии системы покупка активов выполняется за виртуальный рублевый баланс. Для покупки используются валютные пары, цена которых выражена в рублях, например:

```text
USD/RUB
EUR/RUB
```

Это сделано для того, чтобы избежать смешивания валют расчета и упростить учебную модель симулятора.

## Возможные проблемы при запуске

### Ошибка подключения к PostgreSQL

Если приложение не запускается из-за ошибки подключения к базе данных, необходимо проверить:

- запущен ли PostgreSQL;
- создана ли база данных;
- правильно ли указаны логин и пароль;
- совпадает ли название базы данных с настройками в `application.properties`.

### Ошибка подключения к Redis

Если приложение использует Redis для хранения сессий, необходимо убедиться, что Redis запущен.

При использовании Docker можно выполнить:

```bash
docker ps
```

Если контейнер Redis не запущен, его можно запустить командой:

```bash
docker start endurance-redis
```

### Ошибка версии Java

Если при запуске появляется ошибка, связанная с версией Java, необходимо проверить установленную версию:

```bash
java -version
```

Для Spring Boot 3 рекомендуется использовать JDK 17 или выше.
